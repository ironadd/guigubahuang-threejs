# 鬼谷八荒 · 登仙境大成斗法演武 (Three.js Demo)

基于 **Three.js + UnrealBloom HDR 辉光后处理 + Web Audio 程序化修仙音效** 构建的《鬼谷八荒》后期（羽化 / 登仙圆满）大成剑修秘境战斗演示。

- **在线试玩 (GitHub Pages)**：https://ironadd.github.io/guigubahuang-threejs/

## 本地快速启动

双击运行目录下的 **`启动演武场.bat`**，或在终端执行：

```bash
npm install
npm run dev
```

随后在浏览器访问 `http://localhost:5188`。
